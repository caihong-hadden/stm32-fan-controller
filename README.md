# RTX 4090 显卡风扇测控

> 接管显卡风扇前先搞清线序：HEX 固件解析 + 实测调速曲线。

## 它解决什么

显卡风扇的转速曲线由板载固件决定，想接管就得先搞清楚**这根线到底是 PWM 还是测速、极性怎么排**。接错一次就是烧驱动。

## 做了什么

- 从风扇模组的 HEX 固件里解析出调速表与引脚复用关系
- 用万用表与示波器逐一验证线序，把「哪根是 12V、哪根是 PWM、哪根是 TACH」落到实测结论而不是靠猜
- 记录不同占空比下的实际转速，得到可复现的调速曲线
- 留下硬件照片与拆解记录，便于复现

> 仓库不含厂商固件原始文件，只保留解析结论与实测数据。

## 技术栈

- **对象**：显卡散热模组风扇（PWM 调速 + 转速反馈）
- **工作**：固件 HEX 解析、引脚线序映射、调速曲线实测
- **形式**：动手记录 + 脚本
